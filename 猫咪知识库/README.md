## 使用原则

1. 健康问题回答必须附"不替代兽医诊断"边界；急症条目（尿闭/张口呼吸/猫瘟）优先返回就医指引
2. 价格条目注明"区间参考 + 数据日期"，不作精确报价
3. 折耳、极端扁脸等伦理敏感品种，回答时包含风险/伦理提示，不做购买推荐
4. 社群口径内容（小红书等）与权威来源（CFA/TICA/PetMD）冲突时，以权威来源为准并标注差异
