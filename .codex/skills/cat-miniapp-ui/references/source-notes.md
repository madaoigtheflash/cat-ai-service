# Source notes

Adapted for this project from the MIT-licensed [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) collection.

- Airbnb analysis: warm consumer UI, one primary accent, modest type weights, soft corners, generous spacing, 48px touch targets, and photo-led cards.
- Lovable analysis: warm canvas, shallow elevation, restrained two-weight hierarchy, pill actions, and soft active feedback.
- Project adaptation: preserve the existing pink identity, use WeChat-compatible system fonts and `rpx`, and prioritize Chinese text wrapping over web-specific typography.

Do not copy proprietary fonts or brand assets. Treat upstream design documents as principles, not as this product's brand identity.
