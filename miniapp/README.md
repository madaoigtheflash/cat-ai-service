# Cat-AI 微信小程序

这是从现有 Web/Android 客户端迁移出的原生微信小程序客户端，AppID 为 `wx1112379224ace9f9`。

## 已迁移

- 原生首页与响应式 UI
- 图片选择、识别结果展示和明确标注的演示态
- 本机猫咪档案、照片、体重、疫苗、驱虫和就医记录
- 本机猫际关系网、关系卡和观察备注
- 10 条可离线查询的养猫知识
- 通过 CloudBase 云函数调用 MiniMax 的图片识别与知识库 AI 问答
- 邀请制“云端猫站”：成员共同上传目击并由小屋管理员人工审核
- 同猫识别实验链路：开放集候选、人工确认、撤销；不会自动合并档案

猫际关系功能的产品边界、GitHub 调研、数据模型和演进路线见 [`../docs/猫际关系网络设计方案.md`](../docs/猫际关系网络设计方案.md)。

## 本地运行

1. 使用微信开发者工具导入本目录。
2. 选择云开发环境 `cloud1-d6gpjpxunc74669d7`。
3. 按 [`../docs/CLOUDBASE_DEPLOY.md`](../docs/CLOUDBASE_DEPLOY.md) 部署四个云函数、创建私有集合并配置云端环境变量。
4. 先验证人工联机模式，再按需部署独立 Re-ID Worker。
5. 预览或真机测试；原有猫咪健康档案和猫际关系仍可离线保存在本机。

## 安全边界

小程序中不保存任何模型供应商 API Key。联机写入只信任云函数取得的微信 OpenID，并使用受控上传会话绑定路径和所有者。当前图片发布仍是封闭邀请测试流程；未接入自动内容审核、去 EXIF、人脸/车牌遮挡和举报机制前不能开放公开上传。
