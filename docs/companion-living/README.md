# 小桃陪伴版 2.1.0

以对话收敛版为基础的正式项目整合与 UI 活力优化。项目 AppID `wx1112379224ace9f9`，开发源仍为独立受控工作树，不覆盖旧目录里的 Android、管理端和其他未提交改动。

## 这次可体验什么

- 进入“聊聊”看到原创虚拟猫小桃；轻触获得本地预设回应，不会代替你发送消息，也不写入聊天历史。
- 两句开场提示只填入草稿，仍由你编辑并发送。照片选择只在本机预览，主动观察才上传。
- 已有对话不重复大欢迎区，空间让给消息、照片和确认卡。猫咪、双方关系与粗位置沿用原登记数据，不建立重复档案系统。
- 减少动态保留文字回应；动画只在轻触时发生，不播放声音、不做持续漂浮，也不伪装成真实猫咪情绪。
- 历史页改成“和猫咪的小日子”，实际数量并入分类入口，历史确认回执与当前档案明确区分。
- 本机地图突出约 2 公里的粗区域；不自动定位、上传或推断猫咪实时位置。
- 社区、评论、小屋新增/加入/邀请及原有工具继续保留。

**能力边界：本版本使用本地固定规则，不是自由生成对话。** 未完成发布前置的云端文字入口在界面和执行路径都关闭；没有偷偷启用模型服务。既有照片服务仍按用户主动操作调用。
