# 个人故事册与相遇地图 · 副页排版决定

本轮仅改 `companion-data` 和 `companion-map` 的 WXML / WXSS；不改变数据服务、权限、写入、定位、导出或跳转语义。模式为 Operate / Read，继承既有奶白、柔粉、深玫红和中文系统字体，不另造品牌。

## 我的数据：先看到生活，再核对记录

- 将四块大数字统计卡移除。猫档案、双方关系、对话历史的真实数量并入分类按钮，粗位置数量并入地图入口；不发明活跃度、连续天数、陪伴时长或示例故事。
- 页内标题为“和猫咪的小日子”，原生导航仍为“我的数据”。正文之后直接保留“只读本机、不代表云端全量、不自动同步或公开”的范围说明。
- 猫档案是可点开的头像目录；双方关系用上下相邻的文字保留两端身份和方向；确认回执是历史保存事实，仍在历史消息之前，并保留“不代表记录现在仍存在”。
- 回执从嵌套卡片改为分隔清楚的纵向列表。历史消息使用奶白 / 柔粉区分本人和回复，真实时间与来源可换行；不把旧消息改写成当前状态。
- 留白用于区分阶段，正文与辅助说明分别为 26–28rpx / 23–24rpx。标题 44rpx；不使用远程字体、全屏动画或装饰纹理。

## 地图：回看相遇，不追踪行踪

- 把地图做成主内容，移除重复卡片外壳；奶白页面、柔粉选中记录和原生底图各承担一种信息角色。
- 页内标题为“猫咪相遇地图”，原生导航仍为“本机猫咪地图”。标题后的粗范围 / 不获取当前位置 / 不上传说明保留。
- 地图下保留中心标记、模糊圆圈与“不提供精确地点导航”的提示；选中猫名在前，“选中的记录”是其附属状态而非装饰标签。
- 可访问的文字列表与地图等价，包含真实猫名、粗区域、时间和选中状态。已删猫档案、位置格式异常、空数据仍沿用现有诚实反馈。
- 小屋入口与本机地图分开，不把小屋协作数据假称为用户私有总量。

## 工程与验证边界

- 沿用现有图标组件，无新增位图 / 外部图 / 字体 / 纹理。全局 DESIGN.md 与 sidecar 不变。
- 本页所有按钮局部覆盖微信非 mini 按钮默认宽度：`min-width:0; max-width:100%; box-sizing:border-box`；保留至少 88rpx 触控区、自然换行及底部安全区。
- 320px 等窄屏分类按钮把数量下排，头像轻缩；地图选中猫名与状态可上下分行。重要文字均不单行省略，无固定文本高度。
- 本子任务仅做相关自动化回归；原生截图由主任务统一批量核验。未据源码宣称真机、大字号或键盘已经通过。
- 本子任务验证：`companion-data.test.cjs` 23 / 23 通过、0 失败、0 跳过；微信开发者工具原生 WCC / WCSC 对两页四个模板与样式文件编译通过；`git diff --check` 无空白错误。未执行部署或云端调用。
