# 06 · 私人猫咪日记

分支：`codex/cato-lab/journal`。入口：`/pages/cato-journal/index`。

## 实现范围

- 原生小程序日期、标题、正文、可选手动猫咪称呼；创建、原位编辑、确认删除。
- 标题 1–60 字、正文 1–4000 字、称呼 0–60 字；严格日历日期，范围 1900–2199 年。
- 标题／正文／称呼搜索与日期筛选可叠加，按日期倒序回顾。
- 日记仅通过 `createStore('journal')` 写入 `catai_cato_lab_v1:journal:entries`；不读取原猫档案或照片。
- 保存后维持同一日记 ID，重复保存幂等；取消编辑需确认；失败保留编辑内容与此前成功保存的记录。读取损坏数据时禁止覆盖。
- 分享草稿初始为空，主动选择一个短片段或手动改写。片段候选严格短于正文，不自动复制整篇。
- 公开／一个模拟小屋必须明确选择；选择片段会重置可见范围，改写或切换范围使旧预览失效。换来源重置草稿为空。
- 预览字段仅有文字、目标范围、模拟标识与未发布标识；不带私人标题、日期、猫咪称呼、来源 ID、照片或医疗字段。
- 分享草稿和预览只在当前页面内存，取消或离开即清空，不删除私人日记。修改来源日记会清空旧分享草稿，绝不自动扩充公开文字。

## 操作步骤

1. 微信开发者工具导入本工作树 `miniapp/`，游客 AppID；方案审计入口 → 打开本分支实验。
2. 写日期、标题、正文与可选称呼，点击保存两次；确认只有一篇，重进页面后还在。
3. 编辑正文，取消时先拒绝再确认；已保存记录应不变。搜索一个正文关键词，再叠加日期，清除筛选恢复列表。
4. 删除时先取消；记录应保留。确认删除会永久清除此篇本机日记，界面明确不可撤销。
5. 点击「为这篇另建分享预览」：分享框与可见范围均为空。选一个片段或手动改写，再选公开并生成预览。
6. 切换到「午后猫窝 · 一个模拟小屋」：旧预览消失，需要重新核对；新预览只有编辑框文字与目标范围。
7. 取消分享后检查日记仍在。为另一篇建立分享：文字和范围应重新为空。
8. 审计标准字号与大系统字号下的换行、按钮、日期选择器和底部安全区。长日记不截断。

## 模拟与隐私边界

- 没有真实云同步、社区发布、通知、分享接口、跨设备恢复或实际小屋权限校验，不调用 `community.saveDraft`。
- 「午后猫窝」只有本地模拟名称，没有真实成员。公开也只是本机预览，不代表互联网可见。
- 手工猫咪称呼仅为日记参考字段，不是原档案关联。没有默认示例日记，也不自动导入任何个人资料。
- 本机实验存储不是加密保险箱。同一设备具有小程序访问权的人可能看到日记；清理数据或卸载会丢失已保存内容。未保存编辑草稿离开页面也不会自动持久化。
- 文字由用户主动选择或重写，不做敏感信息自动识别；预览前仍应人工检查私人细节。健康文字仅作记录，不替代兽医诊断。
