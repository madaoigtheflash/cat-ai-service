# 11 · 有向猫际关系观察计划

分支：`codex/cato-lab/relationship-observe`。基线：`0dde597`。仅供本机独立审计，不自动合并、发布或写入云端。

## 实现范围

- 三只明确标注的合成猫；只能选两只不同的猫。提供主动接近、跟随移动、发起梳理三类中性行为假设，起点与终点角色分别显示。
- 一个有序猫对只有一份计划。A → B 和 B → A 独立保存，反向新建不复制证据、角色结论或票。保存后方向和行为类型不可改写；时间和观察清单可编辑、取消。
- 用户亲自选择观察日期和时间，没有默认替用户决定，也没有通知或推送。支持分时证据笔记、按时间回顾、撤回并留存撤回标识。
- 两位明确模拟观察者可切换身份，各自投票、改票、撤回；每人每方向唯一一票。计数表仅从当前方向已保存的本地票计算，没有种子票、热度或概率。
- 所有投票必须引用本方向有效证据。撤回证据时同时撤回引用它的票；没有有效证据则不能投票或完成，撤回最后一条证据会恢复“记录中”。完成后可以撤销，保留证据与票。
- 领域函数仅处理显式传入的数据，不访问微信、原档案、照片、健康记录、私信、模型、网络或云 API。只使用 `createStore('relationship-observe')`，键为 `catai_cato_lab_v1:relationship-observe:state`。

## 操作步骤

1. 导入此工作树的 `miniapp/`，保持游客 AppID。首次进入“方案审计入口”，再点“打开本分支实验”。初始无保存计划或投票。
2. 选糯米作为起点、芝麻作为终点，选择行为假设，核对两边角色；选择日期与时间，编辑清单，保存计划。
3. 在当前方向下填写实际用于演示的分时笔记，明确属于虚构观察，选择记录时间后保存。可添加第二段不同时间的笔记。
4. 勾选有效证据，以“观察者小禾（模拟）”选择判断并投票；再切到“观察者阿宁（模拟）”投另一票。下方计数表应随本地保存结果改变。
5. 对同一观察者改票，检查总票数不超过 2；撤回一票，检查对应类别减少。撤回其引用证据时，检查相关票一并撤回。
6. 点“另建反向计划”，核对变成芝麻 → 糯米且起终角色正确；新选时间并保存。反向无预置证据和票，原方向记录仍独立可选。两个方向分别保留本页尚未提交的笔记和编辑草稿。
7. 编辑计划后取消，确认保存内容不变且草稿保留；有证据时完成记录，再撤销完成继续补记。
8. 需要清空时返回实验室，使用已有“重置本实验数据”确认流程；只清除此实验命名空间，不处理原版档案。

## 保存与边界规则

- 数据形状、合成猫、模拟观察者、方向角色、判断类别、有效日期、文本长度、唯一证据和投票引用均在纯领域层校验；不接收额外健康等字段。每方向最多 200 条笔记，实验最多 2000 次已接受操作，达到上限不覆盖旧记录。
- 按版本校验后保存。陈旧版本会刷新当前列表并保留草稿，提示用户核对后再保存；不自动覆盖另一页面的新记录。
- 同一提交标识记录原始操作指纹；完全相同的重试不会重复提交，复用标识更改内容被拒绝。保存失败、写后抛错、读回失败、静默丢写均不宣称成功、不清空输入，并锁住其他修改，只允许以同一请求重试核对。
- 初次读取失败或存储损坏不降级为覆盖空记录。确认窗口取消或失败不执行撤回／完成操作。存储异常可能已写入时只说“尚未确认”，核对成功才展示成功。
- 只做本机实验级乐观版本冲突处理，不宣称真正跨设备原子事务、真实账号身份或服务端并发保证。尚未提交的输入与待核对请求保留于当前页面内存，不承诺关闭页面或进程后恢复未保存草稿。
- 自填时间按本机时间解释，校验有效的 2000—2099 年日期，不认证观察真实性。任何笔记和票数都不能证明同猫身份、亲缘、固定性格或道德标签；不生成诊断、治疗和用药建议。
