# 12 · 知识与自定小行动

分支：`codex/cato-lab/knowledge-action`。基线：`0dde597`。这是独立、本机可操作的审计实验，不代表已上线或可合并；最后由用户决定。

## 实现范围

- 白名单只引用 `miniapp/data/knowledge.js` 的 `photo`、`lihua` 两篇既有知识原文，展示来源路径、来源 ID 和适用边界；不生成知识。原条目未附外部参考文献，页面明确说明尚不能视为专业审校。
- 用户亲自填写行动草稿，保存并主动确认低风险边界，之后可以标记完成、撤销完成、取消或重新编辑。没有自动安排、提醒、奖励压力或医疗日程。
- 反馈原文、保存版本、来源 ID、行动版本分开存储。提交必须明确确认，只进入本机模拟队列。修改已审阅反馈时即撤回原模拟审计；保存形成新版本，不能沿用旧报告或决定。
- 用户点击后，固定本地关键词和模板生成问题筛选、可行性提案预览；规则名是 `local-templates-v1`。健康词优先、其次使用体验、知识表达、普通体验；所有分类只是线索，不代表已复现问题或验证内容。
- 人工同意/驳回与撤销决定均可操作。同意仅保留当前版本提案，不调用 Codex、不执行命令、不修改代码、不创建开发任务、不发布或真实发送。
- 只调用 `createStore('knowledge-action')`，存储键为 `catai_cato_lab_v1:knowledge-action:session`。没有原档案、原照片、真实意见信箱、账号或云 API 读写。

## 数据与失败约定

纯状态逻辑位于 `miniapp/utils/cato-knowledge-action.js`，依赖只读的既有知识数组，不依赖界面或存储 API。

| 数据 | 独立字段与约束 |
|---|---|
| 知识 | `sourceId`，仅 `photo` / `lihua` |
| 行动 | `text` / `revision` / `status` / `acknowledged` |
| 反馈 | 完整 `raw` / `version` / `history`，每版关联来源和行动版本 |
| 模拟队列 | `submittedVersion` / `queueId`，提交当前版本且行动已完成 |
| 模拟报告 | `ruleset` / `feedbackVersion` / `actionRevision` / 固定提案文字 |
| 人工决定 | `actor: user` / `value` / `reportId` / `feedbackVersion` / 用户说明 |

保存成功后才更新成功状态。写入失败保留前态与当前页输入，可重试原按钮；重复确认、完成、提交、审计和同决定不重复创建反馈版本。修改行动后保留反馈原文，但必须重新核对、保存以绑定新行动版本。未保存反馈会阻止更改行动状态，防止输入意外丢失。

来源、状态、版本链、报告和决定在读取时校验；未知或损坏数据阻止继续写入，不能默认为完成或同意。读取失败可重试，未自动覆盖。决定撤销回到待人工审阅，撤销完成/取消行动/编辑反馈使旧模拟报告和决定失效。

反馈原文及人工理由仅通过普通文本绑定显示；不使用 HTML 渲染、指令解析、动态函数或命令拼接。关键词检测不属于全面医疗安全审查，不能发现所有不合适行动；最终仍依赖用户低风险确认，健康问题交由执业兽医。

## 操作步骤

1. 在微信开发者工具导入本工作树 `miniapp/`；项目保持 `touristappid`。首路由为方案审计入口，点击「打开本分支实验」。
2. 选择任一既有知识，核对来源 ID、原文和边界。填写如「在不打扰猫咪的情况下观察窗边光线」，保存草稿，主动勾选式确认边界，再确认行动。
3. 点击「我已完成，记一下体验」。写反馈并保存，检查保存版本。此时没有进入队列。
4. 明确提交到本地模拟队列，在确认弹窗点「返回」应不提交；点「确认」后显示模拟队列 ID。
5. 点击「运行本地模板化审计」。分别用健康相关、保存失败、知识说明、普通观察文字体验固定分类，核对页面一直说明「模拟、固定模板」。
6. 人工同意或驳回，可填写理由；确认后只出现本地决定，不会执行开发。撤销决定可重新选择。
7. 修改反馈一个字：旧报告立即撤回；保存产生新版本。即使改回原文也不会复活旧决定，需重新提交与审计。修改行动同样使旧审计失效。
8. 测试「模拟下一次保存失败」：保存草稿、提交队列或保存决定失败时，不出现成功状态，输入保留；再次点原按钮可重试。
9. 测试撤销完成、取消行动、重新编辑与重进页面；已经保存的草稿/版本恢复。尚未保存的输入退出页面可能丢失，页面已提醒。
10. 需要换来源时，回方案审计入口确认「重置本实验数据」。当前只保留一组行动与反馈历史；重置只删除本实验命名空间，不能恢复这些实验草稿，不影响原档案。

## 模拟边界与未验收项

- 队列、审计与提案均是本地模拟；没有真实反馈 API、模型审计、Codex 接入、网络请求、后台任务或代码执行。人工同意不是开发授权，也不会触发开发。
- 内置知识未在本次进行外部资料核验，不新增医学结论。健康警示沿用项目医疗安全措辞，不用模板判断病情或是否紧急。
- 关键词规则仅演示筛选流程，不能验证漏洞、知识真伪、可行性成本或医学安全；相关结论要另外人工核验。
- 已按 `cat-miniapp-ui` 规范使用粉色卡片、系统中文字体、自然换行、88rpx 触控和底部安全区；未自行声称通过开发工具截图、320/375/430px、默认/大字体或真机交互验收。主代理负责另行截图，最终仍需用户视觉与手动审计。
- 单机一个活动行动、手动完成、手动提交；无多端同步、多人队列、后台推送、真实存储满额设备测试。模拟失败用于本地故障契约验证。
- 存储失败时不能保证修改持久化；页面会保留当前输入和失败提示，不称其已保存。必须重试保存成功后才能把新版本视为持久记录。
