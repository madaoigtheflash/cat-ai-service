# 可控制的猫咪陪伴：审计说明

分支：`codex/cato-lab/companion`。实验入口：`/pages/cato-companion/index`。

## 实现范围

- 昵称、AI 助手自称（各 1–12 个 Unicode 字符，保存时去除首尾空格）、温柔／简洁语气。
- 开始／中断／结束三个本地文案场景，修改草稿立即更新。身份始终标为 AI 示例，不模拟真人猫友回复，不制造连续打卡压力。
- 页内提示默认关闭。安静时段默认开启，22:00–08:00 跨午夜；开始包含、结束不包含，起止相同明确表示全天安静。
- 明确标注的模拟本地钟点选择器及 23:00、07:59、08:00、12:00 快捷值。点击试验后，结果随草稿或模拟钟点更新；安静时段内不展示示例提示正文。
- 减少动态默认开启；关闭后本页指示点播放舒缓呼吸动画，开启立即移除动画类并应用 `animation: none`。保存的用户选择会恢复。另提供宿主支持时生效的 `prefers-reduced-motion` CSS 保护，但不宣称已读取微信／操作系统设置。
- 保存、放弃草稿、恢复并保存默认偏好均有确认。保存仅在写入成功后更新已保存状态；取消不写入，读失败阻止覆盖并提供重试；重置失败保留原草稿；重复保存不重复写入。
- 纯业务模型与可注入控制器。无后台计时器、订阅消息、生产云调用或原版设置读取。

## 数据与真实／模拟边界

唯一写入键为 `catai_cato_lab_v1:companion:preferences`，由 `createStore('companion')` 生成。仅保存 8 项偏好字段；模拟时间、选择的场景、提示文案和试验结果不落盘。重置仅将这一个偏好键恢复为默认，不碰其他实验、原档案、照片或云端数据。

本分支是实际可持久化的本机偏好实验，不是微信免打扰、后台通知、多端同步或云端人格设置。所谓“提示”仅是用户主动点击后在本页呈现的示例块；没有向他人发送任何内容。主动查看场景文案不受安静时段影响，并已在界面说明。

未知系统动效偏好时使用保守默认“减少动态开启”。页面可由用户明确关闭，并保留其上次保存的选择。CSS 媒体查询是否得到宿主系统支持仍需真机确认；无需也未新增未经核实的系统 API。

## 建议验收步骤

1. 用游客工程导入本分支 `miniapp/`。方案审计入口应显示“可控制的猫咪陪伴”，打开本分支实验。
2. 核对标题后紧接本地／AI／无真实通知范围提示。改昵称为“阿桃”、助手自称为“小云”；切换温柔／简洁及开始／中断／结束，确认预览立即更新。
3. 在默认设置下点击“试一次页内提示”，应显示“页内提示已关闭”，没有提示正文。
4. 打开“允许本实验页内提示”：23:00 与 07:59 均被安静时段拦住，08:00 与 12:00 显示示例提示。只改变模拟钟点，不改变设备时钟。
5. 将起止都设为 08:00，应显示“全天安静”并拦截所有模拟钟点；关闭安静时段后，允许页内提示时才可展示。
6. 减少动态默认开启，圆点静止；关闭后圆点呼吸，重新开启后静止。若系统减少动态媒体查询生效，即使手动关闭也可继续静止，属保护性行为。
7. 修改后点保存，先取消，确认草稿仍在且状态为未保存；再次保存确认，退出后重新打开，偏好应恢复，但模拟时间与场景回到初始值。
8. 修改后放弃，先取消再确认，核对两条路径；恢复默认同样验证取消／确认，确认后页内提示关闭。
9. 输入空格或超过 12 字的称呼，保存应显示错误且不弹确认。使用测试驱动模拟读写失败时，不得报“已保存”，并可重试。
10. 微信模拟器与真机各检查默认和大号系统字体：操作至少 88rpx、中文自然换行、底部安全区，无内容裁切或遮挡。视觉截图与真机结果由总审计补充，不用单元测试替代。
