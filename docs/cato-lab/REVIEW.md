# 03 · 小屋协作目标审计

分支：`codex/cato-lab/house-goals`。本分支只实现此方向，没有合并其他实验、发布小程序或连接生产云。

## 可体验范围

- 本地合成邀请小屋：小林（初始房主）、阿乔（已接受邀请的成员）、屋外访客。页面始终注明模拟身份与“云端未连接”。不是微信身份、真实邀请或真实小屋。
- 有效成员可创建目标、添加用户自定子任务，并填写可选截止日。目标创建者或现任房主可编辑目标及未认领子任务；认领后的子任务只允许认领者编辑，完成后需先撤销。
- 所有任务初始未分配，成员必须以当前模拟身份主动认领。无代他人分配、后台任务或真实通知。
- 认领者可填写可选完成记录、完成、撤销、释放。撤销会清空该次完成记录；完成任务必须先撤销才能释放。目标显示完成数量及比例，空目标为 0%。
- 退出立即撤销该身份的页面和域层访问权，清空页面目标、输入表单与完成记录。未完成认领释放，已完成记录保留为小屋历史（标记认领者已退出）。房主退出交接给剩余成员；最后一人退出关闭小屋。没有自动重新加入，需在入口重置实验才能重新开始。
- 日期支持留空，严格校验真实的 `YYYY-MM-DD`（1900–2199 年，包括闰日）；子任务日期不能晚于已设置的目标截止。不自动生成诊断、药量或治疗计划。

## 实现及模拟边界

`miniapp/utils/cato-house-goals.js` 是无微信 API 的纯状态域模块：接收 actor，所有读写检查成员资格；对非成员只返回空目标/成员投影。页面不持有后端原始房间状态。任务认领冲突、他人任务操作、过期编辑及退出限制在域层执行，不只依靠隐藏按钮。

`createBackend` 每次命令重新读取已保存状态，只有保存成功后才返回成功投影。相同认领、相同完成、重复撤销及释放不会产生重复写入。模拟两个顺序客户端可复现第二次认领冲突；这不是跨设备并发事务、真实后端授权或网络同步的实现。

数据仅用共享 `createStore('house-goals')` 写入 `catai_cato_lab_v1:house-goals:room`。没有读取原档案、真实健康数据或照片。数据为本机明文实验存储；同一设备上的审计者能切换身份或访问存储，**不构成对设备所有者的安全隔离**。未来接入须将 actor 绑定真实登录态，在 CloudBase 服务端事务与权限层重新实现和验收；本分支不调用生产云。

存储写入失败不显示成功、保留表单及上次成功状态；读取失败隐藏内部内容，不自动重置覆盖。页面提供“模拟下次保存失败”按钮，仅让下一次有数据变更的写入抛错一次。编辑中切换身份会清空未保存草稿，并在界面提前说明。取消编辑、撤销完成、退出均有确认对话框。

## 审计操作步骤

1. 微信开发者工具导入此工作树的 `miniapp/`（游客 AppID），打开“方案审计入口”→“打开本分支实验”。核对标题、模拟说明与云端未连接。
2. 用小林身份“新建共同目标”，如“整理猫咪用品”，截止 `2026-10-31`；添加两个自行命名子任务，截止 `2026-10-20` 和留空。检查 0/2、日期显示。编辑目标与未认领子任务，确认变化。
3. 对第一项点“我来认领”，写完成记录后确认完成；检查 1/2 和 50%。撤销对话框先取消一次（状态不变），再确认（回到 0/2、完成记录清空）；再次完成后核对。
4. 切换阿乔，认领第二项；核对房主不能代为完成、释放或编辑这项任务。以阿乔编辑自己任务，再释放；切回小林可重新认领。真实的第二次认领竞态由下述域层测试覆盖，不把单设备页面视为并发验收。
5. 在任一编辑框输入无效日期 `2026-02-30` 保存，检查错误和输入保留；输入晚于目标的子任务截止也应拒绝。将目标截止提前到已有子任务之前应拒绝。
6. 在编辑框保留标题、日期或完成记录，点击“模拟下次保存失败”，再保存：不出现成功、内容不丢失、已保存列表不变；再次保存应成功。取消编辑对话框先取消，确认草稿仍在；再确认取消，确认未写入。
7. 切换屋外访客：目标名称、子任务、完成记录、旧表单与反馈全部不可见；只有无访问权提示。切换回有效成员后内容恢复，未保存草稿不恢复。
8. 小林认领一个未完成任务后退出：先取消退出确认，状态不变；再确认。该身份立即无权访问，未完成任务释放；切至阿乔显示房主。小林的已完成记录仍保留为历史。阿乔最后退出后所有身份均看不到内部目标。
9. 返回入口重置本实验，重新打开后恢复两个合成成员及空目标；原版档案和其他实验数据不变。
