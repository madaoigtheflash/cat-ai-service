# 04 · 猫友专注陪伴（focus）

分支：`codex/cato-lab/focus`。这是现有 Cat-AI 柔粉原生小程序的独立离线扩展，不是新品牌，也没有生产云连接。

## 已实现的可操作闭环

- 用户自行选择「安静陪伴」或「学习充电」，填写 1–60 字活动名称。
- 番茄钟：专注 1–180 分钟、休息 1–60 分钟，均为整数；或正计时。
- 一个主计时操作随状态变为开始、暂停、继续、开始休息、再专注一轮。结束并核对是次操作。
- 以持久化时间戳和已累计时长计算用时；一秒刷新仅绘制界面。暂停空档不计入；返回页面或重建控制器恢复当前状态。
- 番茄钟在当前阶段上限封顶，不将后台超出的时间计入，不自动开始休息或下一轮；用户主动切换。休息不算专注时间。
- 「结束并核对」先成功保存暂停状态，再展示确认表单。可改名称、加标签、主动标记本人任务完成；默认不标记完成。取消后仍暂停，可以继续。
- 确认保存将记录和清除 active 放在同一存储对象中；相同会话 ID 的重复确认仅返回原记录，不重复生成记录，也不影响新会话。
- 已确认记录可编辑名称、专注分钟数（0–10080，可为小数）、结束日期、标签（最多 5 个，每个最多 16 字）、本人完成标记。标签支持中文/英文逗号、顿号和换行分隔并去重。
- 日、周、月统计即时重算，只计已确认记录的专注分钟数和次数。以设备本地时区、记录结束日期归属，本周周一开始；跨午夜的一次记录全部归入结束日期，不按时间片拆分。

## 本机运行与操作步骤

1. 微信开发者工具导入本工作树的 `miniapp/`；游客工程，入口保持 `pages/cato-lab/index`。
2. 点击「打开本分支实验」，确认顶部显示「本机离线实验」。
3. 选学习或陪伴、填写名称。番茄钟可设为专注 1 分钟/休息 1 分钟，开始并等待到点；确认到点不会自动进入下一阶段。
4. 自行开始休息，然后再专注一轮；或随时「结束并核对」。核对中取消，应仍保持暂停。
5. 再进入核对，保留完成开关关闭，确认保存：记录应显示「仅记录时间，未标记任务完成」。
6. 编辑记录的时长、日期、标签及完成开关，保存后核对统计；取消编辑不改变原记录。
7. 使用正计时测试暂停、继续、返回上一页后重进，以及关闭/重新编译后重进：时长应来自时间戳而非页面刷新次数。
8. 审查大号系统字体、窄屏、长中文名称、键盘展开和底部安全区。此项由主审计任务执行；这里不声称模拟器或真机验收完成。

## 数据、失败与安全边界

- 只使用 `createStore('focus')` 写入 `catai_cato_lab_v1:focus:state`，不导入或改写原猫咪档案，不读取照片，不写其他实验。
- 内存状态只在同步保存成功后推进；开始/暂停/继续/换阶段/确认结束/编辑保存失败均保留先前状态并可重试。结束失败保留暂停会话与核对表单，不报成功。
- 读取失败或存储结构异常时禁用修改并允许重读，不静默用空对象覆盖既有数据。用户仍可自行到实验入口决定是否重置。
- 系统时间回拨不累加负时长，界面提示核对时间；设备时钟不是可信服务器时钟，可人为调整，记录也允许事后编辑。
- 无微信订阅消息、后台通知、云写入、真实任务联动、动物自动运动安排或医疗建议。任务完成开关只代表本人本机实验标记。
- 没有自动插入示例完成记录，没有连续打卡、奖励或惩罚。清理缓存、卸载或入口重置会丢失本机记录，暂无导出/备份。
- 不实现跨端同步、真实云端恢复、任务关联、精确跨日时间拆分或真实后台提醒；这些需要后续独立授权和沙盒验收。
