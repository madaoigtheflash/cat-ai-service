### 候选模型

- 来源：[`open-noodle/pet-recognition-small`](https://huggingface.co/open-noodle/pet-recognition-small)
- 许可证：Apache-2.0
- 文件大小：89,227,604 字节
- SHA-256：`6a5e2373ab348bed588cef4072f3914ca9c8bacde3e8d0651019e8dad86b24ba`
- 输入：`float32 [N, 3, 224, 224]`，RGB，ImageNet mean/std
- 输出：`float32 [N, 512]`，L2 归一化
- 当前执行后端：ONNX Runtime 1.24.3 CPUExecutionProvider

模型文件保存在忽略目录，不提交到代码仓库。

### 本地小样本结果

项目中只有两张不同猫的唯一原图，其余上传图是这两张图片的重复文件。因此本轮采用：

- 两张不同猫原图；
- 每张图在内存中生成镜像、亮度变化、JPEG 质量 55 和中心裁剪 90% 等扰动；
- 不将人工扰动视为真实跨拍摄正样本。

结果：

| 项目 | 结果 |
| --- | ---: |
| 输出向量范数 | 1.0 |
| 同图扰动相似度最低值 | 0.936615 |
| 同图扰动相似度平均值 | 0.978763 |
| 两只不同猫所有扰动组合最高值 | -0.012682 |
| 当前样本分离间隔 | 0.949297 |
| ONNX 会话加载 | 约 501 ms |
| 桌面 CPU 热推理平均值 | 约 58.5 ms/张 |

当前两张照片区分明显，证明端到端管线有辨别能力。`0.461967` 只是这两个样本的数学中点，不能作为 APK 或生产阈值。

- AI 引用过滤与最高分差距过大的低相关片段。

## 真实数据采集要求

阶段 0 完整验收至少需要：

- 5 只以上猫，建议 10～20 只；
- 每只猫至少 5 张，建议 8～12 张；
- 至少 3 个不同拍摄时间，不能全部来自同一次连拍；
- 包含正面、左右侧面、半身或全身；
- 包含室内外或明暗变化；
- 保留模糊、遮挡、距离过远等失败样本，用于质量门控；
- 同一文件的裁剪、压缩和截图不能分到建档与测试两侧。

目录格式：

```text
validation-cats/
  cat-001/
    session-1-front.jpg
    session-2-left.jpg
  cat-002/
    session-1-front.jpg
    session-3-full.jpg
```

执行命令：

```powershell
python tools/pet_reid/evaluate_dataset.py validation-cats
```

## 阶段 0 晋级门槛

以下是 POC 晋级 Android MVP 的建议门槛，不是宣称当前已经达到：

- 测试身份不少于 5 只，测试图不少于 40 张；
- Top-1 不低于 85%；
- Top-3 不低于 95%；
- FAR 不超过 1% 的工作点上，TAR 不低于 80%；
- EER 不高于 10%；
- 同猫与异猫分数分布不能严重重叠；
- 模糊、无猫、多猫照片能够在身份判断前被拦截或要求用户确认；
- 至少在一台中端 Android 真机确认内存、首帧耗时和热推理延迟。

如果 Top-3 达标但 Top-1 未达标，可以进入“候选列表 + 用户确认”的辅助识别模式；不能进入自动绑定模式。
