# Cat-AI 本地云端管理台

## 用途

这是一个独立的 FastAPI 本地管理台，用来统一查看 CloudBase 环境中的小屋、规范猫身份、本地档案映射、有向关系、目击、粗粒度分布、同猫任务和用户反馈。

小屋、猫、关系、目击和身份数据保持只读。反馈工作流只允许对 `ci_feedback` 和 `ci_change_proposals` 做固定条件、版本校验和写后回读的受控写入。管理台不会把 OpenID、完整 ownerKey、精确位置、云文件 ID、邀请码摘要或 embedding 返回浏览器。

小程序只负责提交反馈和查看本人阶段，不包含管理员模式。Codex 审计、报告审阅和确认修改都在本机管理台完成。

## 首次安装

需要 Python 3.10 或更高版本、Node.js，以及已登录的 CloudBase CLI：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r .\cloud_admin\requirements.txt
```

系统没有 `py` 时，可将第一行改为 `python -m venv .venv`。

## 启动

双击根目录的 `启动云端管理台.bat`，或在 PowerShell 运行：

```powershell
.\.venv\Scripts\python.exe run_cloud_admin.py
```

启动器依次尝试项目 `.venv`、`py -3` 和 `PATH` 中的 `python`。默认地址：

```text
http://127.0.0.1:8510/
```

若同一管理台已经占用 8510，重复启动会识别现有实例并直接打开，不再显示 Node.js/登录状态的笼统错误。若端口被其他程序占用，启动器会明确提示改用其他端口：

```powershell
.\启动云端管理台.bat --port 8511
```

程序只允许监听 `127.0.0.1`、`::1` 或 `localhost`，不能绑定 `0.0.0.0`，也不要通过公网转发。API 同时校验 TCP 来源、loopback `Host`、`Origin` 和 Fetch Metadata，防止网页跨站读取本地数据。

## CloudBase 登录

管理台使用本机已登录的官方 CloudBase CLI。未登录时运行：

```powershell
npx @cloudbase/cli login
```

若自动发现失败，可配置 CLI JavaScript 入口：

```powershell
$env:CAT_ADMIN_TCB_BIN='C:\path\to\node_modules\@cloudbase\cli\bin\tcb'
.\.venv\Scripts\python.exe run_cloud_admin.py
```

主体数据只执行 `QUERY`；反馈审计会执行最小范围的 `INSERT` / `UPDATE`。浏览器不会获得 CLI 登录态或数据库凭证。CLI 登录态本身是管理权限，因此本机系统账号和管理台会话必须视为受信任环境。

## 用户反馈与 Codex 本地审计

1. 用户在小程序“意见信箱”提交类型、标题、说明和可选复现步骤；页面禁止填写联系方式、住址、OpenID 或 API Key。
2. 云函数从登录态生成 ownerKey，只向用户返回自己的标题、阶段和时间。
3. 本地管理台选择 1–20 条 `OPEN` / `TRIAGED` 反馈，做字段裁剪以及 Key、邮箱、手机号和 ownerKey 脱敏。
4. Codex 在 `read-only` 沙箱生成结构化可行性报告；反馈始终是不可信资料，不能成为指令。
5. 报告以 `READY_FOR_LOCAL_REVIEW` 写入云端，只在本地管理台展示。旧的两个审批状态会兼容显示为“等待本机审阅”。
6. 本机操作者审阅建议、风险、修改范围和测试计划后，点击“确认并执行修改”，并在确认框中再次确认。
7. 服务端用版本号和一次性租约认领提案，再调用 Codex `workspace-write`。允许修改当前工作区和运行测试，但禁止自动部署、推送、发布或破坏性操作。

完整契约见[《用户反馈、Codex 审计与本地执行工作流》](./用户反馈与Codex审批工作流.md)。

## 离线快照模式

测试或演示时可传入 JSON：

```powershell
.\.venv\Scripts\python.exe run_cloud_admin.py --snapshot .\snapshot.json
```

文件可直接以集合名为键，也可以包含 `collections` 对象。快照模式默认只读，不能执行云端反馈写入。

## 读取范围

默认每个集合最多读取 5000 条并缓存 30 秒：

```powershell
$env:CAT_ADMIN_MAX_DOCUMENTS='10000'
$env:CAT_ADMIN_CACHE_TTL_SECONDS='60'
.\.venv\Scripts\python.exe run_cloud_admin.py
```

达到上限时，“数据质量”页会明确标记，页面不会把截断数据当作完整统计。

## 当前边界

- 小屋、猫、关系、目击和身份数据只读，不提供合并、删除、解除关联等写操作；
- 反馈提案生成不是数据库事务；报告写入成功但反馈关联失败时必须先检查孤立提案；
- 云端状态不会也不能直接控制本机 Codex，本地确认不可省略；
- Codex 只修改工作区，不自动提交 Git、不推送、不部署；
- 管理台只读取 `ci_sightings_public`，不读取私有精确经纬度，也不生成图片临时链接；
- 有向关系 v2 正式启用前仍须完成唯一索引迁移；
- 同猫视觉 Worker 未部署时只能显示现有任务与模板状态，不能启动真实模型推理。
